# Ctrl+Tab switches tabs by most recent use (issue #148)

- **Why.** Ctrl+Tab walked the strip left to right, so going back to the tab you just left meant
  counting tabs; editors and browsers switch by recent use.
- **Chosen.** Hold Ctrl and press Tab: an overlay lists the tabs by most recent use, Tab moves down,
  Shift+Tab up, releasing Ctrl opens the one chosen, Esc or leaving the window cancels. In a split
  window it switches within the focused area only. Settings > Tab order can restore the strip order.
- **Ported onto main (2026-11-06)** from fd-frontend's stranded branch tab-mru; the Settings selects
  now share one named width (`setting-select`) so the new row adds no raw layout utility.
