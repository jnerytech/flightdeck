# Home: four cards over the last seven days of every host (issue #9, with #123, #210, #211 and #212)

Ported from the stranded `home-kpis` and `home-followups` branches onto current `main`; the Home entries of `DECISIONS.md` there, moved to a file of their own (#304).

- **Home is a route of its own, `overview`.** The page asks every online host for `costs.summary` (when it announces `costs`) and `usage.summary` over seven days and adds them up in `lib/home-kpis.ts`. No new command. The sidebar's first item is Home; the desktop app's fresh window opens on it (`AppStoreOptions.startRoute` is the fallback of `Workspace.restore`, passed by `main.tsx`); a saved window keeps its tabs, and the web demo entry and the tests keep Sessions.
- **Turns that failed and turn time** come from the usage ledger (see the ledger decision). One host without them makes the app's failed turns and success rate unknown ("—"), not zero.
- **The spend card compares with the month's host budgets** (sum of spent over sum of limit of host-scope monthly budgets) while its number is the last seven days: the two periods differ on purpose, and the line says "this month". Day and project budgets do not count.
- **Sparklines** are one accent with no axes, and each says its seven values to a screen reader.
- **Average cost per turn uses the usage ledger's cost** (managed sessions, what the SDK reports) over its turns, so numerator and denominator come from the same sessions; the Spend card uses the transcripts' estimate for all sessions.
- **#212, connecting is not "no host".** Home has one live region (`role=status`) from the first word to the numbers: "Connecting to your hosts…" (hosts not read yet, or one is `connecting`), "No host is connected yet." (all offline or refused), "Reading the hosts…", then "Home is ready." (screen-reader only once the cards are there). It is one element so the change is what is announced. The "some hosts did not answer" line is a polite live text without the `status` role, so there is one status on the page.
- **#211, unknown is not zero.** No host giving costs makes Spend and Tokens `null` (shown "—"); hosts without the `costs` feature are named under Spend. A host that has costs and did not answer is named in the "did not answer" line. Avg cost per turn comes from the usage ledger (managed sessions only) while Spend reads transcripts, so the Avg card says "Managed sessions only".
- **#210, the same days and every host.** The cards pass `period: "7d"` to Costs (a route field now, honoured by the page) and, when more than one online host has costs, `host: "__all__"` (the Costs screen's all-hosts choice, now `ALL_HOSTS` in `lib/costs`). History is one host's list and has no all-hosts form, so Turns opens it (with `from` and `to` for the seven days, new route fields the list starts on) only when one host is online; with several it opens Costs across all of them.
- **Where Home sits in the bar.** `main`'s sidebar was regrouped after these branches were written; Home is the first item of the top block (before Sessions), outside the folding groups, so it is always one click away. The account foot and the Settings foot item of the same branches are separate PRs.
