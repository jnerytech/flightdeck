# Teleport: the app relays a package between hosts (issue #100)

## Context

The maintainer wants to move an idle Claude Code session from one host to another, for example from
the Orange Pi to the Windows PC, and continue it there. A session is a transcript
(`~/.claude/projects/<slug>/<id>.jsonl`) plus a working folder. Hosts never talk to each other:
each reaches the app on its own authenticated channel.

## Decision

- **The app relays a teleport package** from the source daemon to the target daemon, over the
  channels that exist. No daemon-to-daemon link is added.
- **The source** (slice 1):
  - `teleport.prepare` packages an idle or ended Claude Code session outside a team.
  - The transcript is the file the history indexer recorded for the Claude session id. It is never
    a path a client names.
  - The file is read only when the id is a UUID, the file name is `<id>.jsonl`, its folder's real
    path is inside a history root, and the file is regular and not a link (`readRegularSized`,
    `O_NOFOLLOW`).
  - It is copied into `<dataDir>/teleport/<package>/transcript` (folder 0700, file 0600).
  - `teleport.read` returns chunks of 128 KiB in base64. `teleport.cancel` removes the package.
  - A package goes after 30 minutes, and every package goes when the daemon starts.
- **The manifest** carries:
  - the settings (model, permission mode, persona);
  - each part's size and sha256;
  - the number of lines that look like secrets and their kinds. Never their text, in the manifest or
    in the log.
- **The code** travels in the same package as a git bundle (slice 1b):
  - the commits HEAD has beyond `origin/<base>`;
  - a WIP commit of the working tree, built in a temporary index, so the person's index, stash and
    refs are untouched.
- **The target** (slice 2):
  - It refuses when it does not have the project (by project key). Cloning waits for a later slice.
  - It puts the code in a **new worktree** of its own copy of the project, never in the checkout
    the person has open.
  - It writes the transcript under its own slug and resumes the session there.
  - The source keeps everything until the target confirms.

## Discarded alternatives

- **Push a temporary ref to `origin`, and the target fetches it.**
  - It needs push rights on the source, and leaves refs on the remote.
  - Uncommitted work would still need another path.
- **A direct daemon-to-daemon link.** A new peer pairing and a new trust surface, for one feature.

## Consequences

- A transcript of up to 64 MB passes through the app's memory, in chunks.
- The refusals are protocol reasons (`teleport_*`) with texts in both languages.
- Teams, the project memory folder, redaction and cloning are later slices.
